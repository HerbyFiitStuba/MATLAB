E4

Porovnaj rýchlosť A\b a inv(A)*b na matici 500×500.

Pozor: prvé volanie každej operácie je vždy pomalšie (réžia na pozadí). Oba postupy najprv raz spusti naprázdno a až potom meraj — meranie zopakuj 3× a spočítaj priemer.
Ukázať riešenie 
n = 500;
R = rand(n) + n*eye(n);
v = rand(n,1);

x1 = R\v;  x2 = inv(R)*v;      % zahriatie

t1 = 0; t2 = 0;
for k = 1:3
    tic; x1 = R\v;       t1 = t1 + toc;
    tic; x2 = inv(R)*v;  t2 = t2 + toc;
end
fprintf('A\\b       priemerne %.4f s\n', t1/3);
fprintf('inv(A)*b  priemerne %.4f s\n', t2/3);
A\b       priemerne 0.0030 s
inv(A)*b  priemerne 0.0047 s
Ľavé delenie je rýchlejšie — nepočíta celú inverznú maticu, čo je zbytočný medzikrok. Bez zahriatia by ti prvé meranie vyšlo opačne, lebo prvé volanie zahŕňa réžiu navyše.
